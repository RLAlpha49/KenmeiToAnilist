# Project Overview & Purpose

## Project Identity

**Kenmei to Anilist** is a cross-platform desktop application built with Electron that enables users to migrate and synchronize their manga library from Kenmei to AniList.

## Core Purpose

- **Migration Tool**: Import manga collections from Kenmei CSV exports
- **Synchronization Service**: Keep Kenmei and AniList libraries in sync
- **Smart Matching**: Algorithmically match manga entries between platforms
- **User Experience**: Beautiful, modern desktop interface for manga management

## Target Users

- Manga readers who use Kenmei for tracking
- Users who want to migrate to AniList for better community features
- People who want to maintain synchronized libraries across platforms

## Key Value Propositions

1. **Seamless Migration**: One-click import from Kenmei CSV
2. **Intelligent Matching**: Advanced algorithm finds best AniList matches
3. **Flexible Sync**: Customizable synchronization with priority settings
4. **Desktop Experience**: Native app feel with offline capabilities
5. **Automatic Updates**: Built-in updater with optional pre-release channel

## Technical Vision

- **Security First**: Context isolation and controlled IPC communication
- **Performance Optimized**: Three-layer caching and worker thread pools
- **Maintainable Architecture**: Modular structure with clear separation of concerns
- **User-Centric Design**: Responsive UI with smooth animations and error handling
- **Cross-Platform**: Consistent behavior across Windows, macOS, and Linux

## Development Status

- **Version**: 3.0.0
- **Platform**: Electron (Windows, macOS, Linux)
- **Framework**: React + TypeScript + Vite
- **Build System**: Electron Forge
- **State**: Actively developed with regular updates

## Future Direction

- Enhanced matching algorithms
- Support for additional manga sources
- Improved analytics and statistics
- Mobile companion app consideration
- Cloud synchronization options
